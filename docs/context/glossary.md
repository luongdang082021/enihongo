# Thuật ngữ

Tóm tắt: các thuật ngữ tiếng Nhật và kỹ thuật dùng xuyên suốt tài liệu và nội dung bài học.

Trạng thái: đang dùng. Cập nhật: 2026-11-05.

## Tiếng Nhật

| Thuật ngữ | Tên Nhật | Nghĩa dùng trong dự án |
|---|---|---|
| Hiragana | ひらがな | Bộ chữ 46 chữ cơ bản, dùng cho từ thuần Nhật và ngữ pháp |
| Âm đục | 濁音 (だくおん) | Chữ thêm dấu ゛: が ざ だ ば |
| Âm bán đục | 半濁音 (はんだくおん) | Chữ thêm dấu ゜: ぱ ぴ ぷ ぺ ぽ (chỉ hàng は) |
| Âm ghép | 拗音 (ようおん) | Chữ + ゃ ゅ ょ nhỏ, gộp thành 1 nhịp: きゃ しゅ ちょ |
| Âm ngắt | 促音 (そくおん) | っ nhỏ, làm đôi phụ âm kế tiếp: がっこう = gakkou |
| Trường âm | 長音 (ちょうおん) | Nguyên âm kéo dài, chiếm 2 nhịp: おかあさん, せんせい |
| Nhịp (mora) | モーラ | Đơn vị độ dài âm; っ, ん, nguyên âm kéo dài tính 1 nhịp, ゃゅょ nhỏ không tính riêng |
| Trợ từ | 助詞 | は đọc "wa", へ đọc "e", を đọc "o" khi làm trợ từ |
| Romaji | ローマ字 | Phiên âm Latinh; dự án dùng hệ Hepburn |

## Quy ước romaji (Hepburn)

し shi · ち chi · つ tsu · ふ fu · じ ji · を wo · ん n. Trường âm viết bằng cách lặp nguyên âm (aa, ii, uu, ei, ou, oo), không dùng dấu gạch ngang trên đầu.
