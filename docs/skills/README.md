## Cách dùng

Các file này nằm trong `docs/` để làm tài liệu. Muốn Claude Code tự nhận skill, sao chép thư mục skill vào `.claude/skills/<tên>/` (mỗi skill một thư mục chứa `SKILL.md`). Cho tới khi sao chép, có thể yêu cầu agent đọc file `SKILL.md` tương ứng.
