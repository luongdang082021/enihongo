## A short conversation

> A: おはようございます。わたしは ミンです。
> B: おはようございます。わたしは さとうです。
> A: にほんごが すきですか。
> B: はい、すきです。まいにち べんきょうします。

Read this aloud a few times. You already know every pattern in it.

## Particle table

| Particle | Job |
|---|---|
| は | topic of the sentence |
| を | the thing acted on |
| に | time, place of existence |
| で | means, place of an action |
| へ | direction |
| と | together with |
| が | object of すき, subject of あります |
| の | possession |
| か | question |
