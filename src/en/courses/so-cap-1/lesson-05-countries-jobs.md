## Nationality with 〜じん

Add **じん** after a country name to mean a person from there: ベトナム + じん = ベトナムじん (Vietnamese), にほん + じん = にほんじん (Japanese).

## Jobs

Use the same **A は B です** pattern: ミンさんは エンジニアです. For the negative use **じゃ ありません**.

## Asking where someone is from

**どこ** means "where". A polite question: おくには どこですか. Answer: ベトナムです.

## Tip

Many country names are written in katakana. If needed, review the Katakana course before starting the exercises.
