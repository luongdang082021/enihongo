## Five vowels

The first five letters sound exactly like あ い う え お: **a, i, u, e, o**. Every other Katakana letter pairs a consonant with these five vowels.

## How to remember them

- **ア** and **オ** both start with a horizontal stroke; オ adds a hooked vertical and a slanting stroke.
- **イ** and **ウ** both have a slanting stroke; ウ has two short strokes on top and a wide hook.
- **エ** looks like a capital I, the easiest of the five.

## Practice

Read the five letters aloud in order: ア イ ウ エ オ. No common loanword uses only these letters, so we move on to the next rows in the following lesson to start reading words.
